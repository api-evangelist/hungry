# HUNGRY

> HUNGRY (Hungry Marketplace, Inc.) is an Arlington, Virginia workplace food platform
> connecting corporate clients to a curated network of independent chefs and local
> restaurants. Founded 2016 by Jeff Grass, Eman Pahlavani and Shy Pahlevani. Operates
> across 24 US cities and, after the February 2026 merger with Toronto-based hungerhub,
> more than ten Canadian markets. Earlier acquisitions: NatureBox and Garten.

## API availability — read this first

**HUNGRY publishes no public API and no developer program.** As of 2026-08-22 there is:

- No developer portal, API reference, or getting-started guide
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection
- No SDK on npm, PyPI, RubyGems, Maven Central, NuGet, crates.io or pkg.go.dev
- No MCP server, no A2A agent card, no `/.well-known/` discovery documents
- No published webhooks, OAuth scopes, rate limits, error catalog or sandbox
- No published pricing, plans or rate card — every product page is a lead form

A first-party API host does exist at `https://api.tryhungry.com`. It is a private backend
for HUNGRY's own web and mobile clients: it sits behind Cloudflare, sets HSTS with preload,
and returns a plain-text `404 page not found` on every publicly probed path
(`/openapi.json`, `/swagger.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/v1/openapi.json`,
`/.well-known/*`). It is not documented and not offered to third parties. Do not attempt to
integrate against it.

Agents should treat HUNGRY as a **non-API vendor**: contact goes through the website forms,
the phone number, or a sales representative — not through code.
